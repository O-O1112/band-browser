# [需要架構決策] 《腕上浏览器》(Band Web Browser) — 小米手環 9 Pro 實作計畫

為 **小米手環 9 Pro (`336×480`)** 打造話題度極高的「手環也能上網看網頁」極客應用（包名 `io.github.o_o1112.bandbrowser`）。因手環本身不具備 WebView 核心與獨立 Wi-Fi，我們必須先在架構層決定聯網與排版方案。

---

## 1. 架構決策：手環聯網與網頁渲染架構（2 選 1）

| 評估維度 | **方案 A（推薦）：手環 Vela 閱讀器前端 ＋ AstroBox `.abp` 外掛 + 輕量網頁正文解析服務** | **方案 B：純手環 `@system.fetch` 直連 HTTP（僅限 Watch S3/S4 等手錶，Band 9 Pro 不可用）** |
| :--- | :--- | :--- |
| **小米手環 9 Pro 相容性** | **100% 支援**；透過 `@system.interconnect` ＋ AstroBox WASM 插件代為抓取 HTTP/HTTPS 網頁 | **不支援**；小米官方 API 明文規定 Band 9 / 9 Pro 禁用 `system.fetch` |
| **網頁閱讀體驗** | 極佳；代理端自動去掉廣告、JS 與冗餘 CSS，將任意網頁抽取出「標題＋段落＋可點擊超連結清單」，手環零卡頓 | 差；若在手環記憶體有限下自行正則解析整頁 500KB HTML 極易 OOM 閃退 |
| **手環操作與交互** | 支援 **米壇開源鍵盤** 輸入網址/關鍵字搜尋、點擊網頁內超連結跳轉下一頁、上下頁歷史紀錄、收藏書籤與離線快取 | 僅支援少數手錶機型且極易遇到 TLS / 大網頁崩潰 |
| **愛發電商業化潛力** | **極強**；免費可逛預設站點（百科、熱榜、快訊），愛發電卡密解鎖「自訂網址任意門 / 離線存網頁 / 自建代理」 | 無法覆蓋廣大 Band 9 / 9 Pro 用戶群 |

> **架構師建議**：採用 **方案 A（手環端閱讀器＋書籤＋歷史＋米壇鍵盤輸入 ／ AstroBox `.abp` 插件轉發 Relay 解析網頁正文與連結）**，同時內建「離線示範站點（熱榜樣本與百科頁）」，就算未接外掛也能開箱演示與點選超連結跳轉，連上 AstroBox 後即刻暢遊真實網際網路！

## 2. 核心功能與手環頁面規劃 (`336×480`)
1. **瀏覽器首頁與書籤牆 (`home`)**：
   - 頂部網址／搜尋框（點擊喚出米壇拼音鍵盤，可切換輸入 URL 或直接搜尋）。
   - 快捷九宮格導航：**B站熱榜 / 知乎熱榜 / 維基百科 / IT之家 / GitHub Trending / AI 搜尋**。
   - **書籤收藏 & 離線已存網頁**（存在手環本機，斷網也能看！）＋ **AstroBox 連線狀態指示燈**。
2. **極簡網頁閱讀視圖 (`reader`)**：
   - 上方網址欄＋重整鈕，中間可捲動閱讀網頁 **大標題、網域名、分段正文與可點擊藍色 `[超連結]` 卡片**（點擊連結即直接載入下一個網頁並壓入 `Back` 歷史堆疊！）。
   - 底部導覽工具列：**`‹ 后退`**、**`› 前进`**、**`☆ 收藏`**、**`字号`**。
3. **網址 / 搜尋輸入頁 (`address`)**：
   - 整合米壇開源鍵盤（帶 `.com`、`.cn`、`https://`、`www.`、`/wiki/` 快捷鍵）與常用搜尋引擎一鍵切換（Bing / 百度 / DuckDuckGo）。
4. **外掛與網頁解析伺服端 (`astrobox-plugin/` + `src/relay/`)**：
   - 安全抓取目標 HTTP/HTTPS URL，剝除 `<script>/<style>`，回傳精簡 JSON（`title`, `url`, `blocks`: 文字段落與最多 15 條站內外清晰連結），避免超大手環封包超時。

## 3. 驗證計畫
1. **單元測試 (`npm test`)**：驗證 URL 規範化（自動補 `https://` 或轉搜尋詞）、HTML 正文/超連結抽取、相對路徑轉絕對路徑、歷史前進後退堆疊與書籤儲存。
2. **Rust WASM 編譯 (`cargo test`)**：編譯並產出配套 AstroBox `.abp` 插件。
3. **打包與模擬器實機驗收 (`build:rpk` & `verify-emulator.cjs`)**：產出 `dist/io.github.o_o1112.bandbrowser.release.rpk`，於 Band 9 Pro 模擬器實機點開首頁書籤、進入網頁閱讀、點擊藍色超連結跳頁、返回與叫出網址輸入鍵盤，並製作 `1200×800` AstroBox 極簡封面。
